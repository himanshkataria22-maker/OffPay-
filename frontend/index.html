🛡️ Security & Attack Simulator

Offline vouchers use RSA-256 digital signatures and unique nonces. Test system resilience against live attack vectors:

Attack Vector 1: Voucher Tampering

Modifies an offline ₹100 voucher to ₹10,000. Backend catches hash mismatch.

Attack Vector 2: Double-Spend Replay

Submits an already-settled voucher again. Nonce engine blocks duplicate execution.

🔒 Anti-Double-Spend: Nonce verification guarantees every offline payment executes exactly once on the UPI ledger.
