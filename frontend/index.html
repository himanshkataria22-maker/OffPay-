🛡️ Security & Attack Vector Simulator

Test OffPay's cryptographic signature verification and nonce double-spend protection against live attack payloads.

Cryptographic Security Guarantee

Every offline payment produces a canonical SHA-256 digest signed with the payer's RSA-256 private key stored in the browser's WebCrypto enclave.

The NPCI gateway performs asymmetric verification against the registered public key and checks the unique cryptographic nonce to prevent replay and double spending.

🔒 Defense Mechanisms: Nonce registry + RSA SPKI signature verification + Strict trust-tier thresholds.
Attack Vector 1: Voucher Tampering (Hash Mismatch)

Simulates a malicious actor intercepting a ₹100 voucher and altering the payload amount to ₹10,000. Hash verification fails at the gateway.

Attack Vector 2: Double-Spend Replay Attack

Simulates broadcasting an already-settled offline voucher again. The gateway's nonce registry detects the duplicate collision and blocks re-execution.
