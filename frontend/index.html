🛡️ Security & Tamper Lab

Offline vouchers are secured with RSA-256 digital signatures. If a malicious actor intercepts and modifies an offline voucher (e.g. inflating ₹100 to ₹10,000), the backend cryptographic validator detects the hash mismatch and immediately rejects it.

Simulate Attack Vector:

Inject an altered voucher payload with forged signature to test NPCI rejection.

🔒 Anti-Double-Spend: Each voucher contains a unique cryptographically signed nonce and timestamp.
